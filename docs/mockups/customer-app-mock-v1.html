What the customer gets

  • Home = "where are my trucks". Three counters (on road / delivered this month / POD pending) and today's dispatch list with one-tap Track. No finance on the home screen — money lives in Bills, and only if the office switches that module on for this customer.
  • Live tracking = the same map as the driver app (route line, 🟢 loading / 🔴 unloading pins, 🚚 live), plus the "Tracking via" badge the API already returns (DRIVER_APP / GPRS / FASTAG with age) — so a 40-minute-old FASTag ping never pretends to be live.
  • Digital POD = stamp, signature, quantities. Delivered shipments show the POD photo the driver uploaded (once the office has verified it), with unloaded qty, shortage and challan no beside it. Download PDF and share on WhatsApp.
  • Bookings = indent status without the marketplace jargon. Submitted → Under review → Truck being arranged → Truck assigned → Delivered. A load can also be posted with a target rate; offers appear when the office opens it to the market, and "Accept" only requests the award — the desk decides (the AWARD barrier already in production).
  • Every write ("Book a truck", "Accept offer") reads as "sent to office" — the staging fence makes that true server-side.
